14장 발표 슬라이드입니다. `index.html`을 브라우저에서 열거나 GitHub Pages에서 볼 수 있습니다. 이미지·도식·스타일은 HTML에 포함되며, 인용 링크는 원문 사이트로 연결됩니다.

- ← / →, Space, PageUp / PageDown: 슬라이드 이동
- Home / End: 첫 장 / 마지막 장
- F: 전체 화면, ?: 도움말, Escape: 도움말 닫기
- 모바일: 좌우로 밀어 이동
- 인쇄: 브라우저 인쇄 또는 `?print=1`로 전체 보기
